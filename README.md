# TMS570 FreeRTOS

This project is an embedded FreeRTOS application for the TMS570LS1224 platform, designed for a Formula SAE EV ECU. The firmware is centered around three main layers:

- HALCoGen-generated peripheral and RTOS setup.
- The FreeRTOS application in [source/App.c](source/App.c).
- External libraries for framing, serialization, and XBee communication.

The main RTOS objects are defined in an application resource block (static) to avoid runtime heap usage. The application relies on FreeRTOS primitives for most data flow (to keep ISRs as short and simple as possible), using event flags to model periodic events and asynchronous notifications.

Initialization is done in two steps, by first configuring the peripherals that need interrupts disabled. The scheduler enables them once it starts running, and a special hook function is called once to initialize the rest of the drivers.

## FreeRTOS Settings

Some customization settings are not generated by HALCoGen, so they must be manually added to `FreeRTOSConfig.h`:

- `configSUPPORT_STATIC_ALLOCATION = 1` after using `#undef` to force static allocation.
- `configUSE_DAEMON_TASK_STARTUP_HOOK = 1` to run initializations after the scheduler starts (IRQs enabled).
- `INCLUDE_xTimerPendFunctionCall = 1` to defer interrupt processing of a function to the RTOS daemon task.

### OS and Tick Integration

The FreeRTOS port is backed by the TMS570 RTI peripheral. In [source/os_port.c](source/os_port.c) (`prvSetupTimerInterrupt()`), the scheduler setup programs RTI counter 0 compare 0 as the system tick source using `configCPU_CLOCK_HZ` and `configTICK_RATE_HZ`. Other counter blocks and compare registers should be configured there as well (not using `rtiInit()`).

## Submodules

External libraries:

- [cobs/cobs-c](cobs/cobs-c) for COBS encoding/decoding.
- [msgpack/cwpack](msgpack/cwpack) for MessagePack serialization.
- [xbee/digi_xbee_api](xbee/digi_xbee_api) for XBee API frame handling.

After cloning, initialize them with:

```bash
git submodule update --init --recursive
```
